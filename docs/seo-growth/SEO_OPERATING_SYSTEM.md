# SEO Operating System

Date: 2026-06-04

Strategic direction: Oz Timber Floor should run an owner-led SEO system after migration instead of immediately hiring a generic monthly SEO agency. The advantage is trade knowledge, fast implementation, Search Console feedback and controlled Google Ads learning. Outside help should be hired only for clear specialist deliverables.

Do not make broad content or site changes until the production migration is completed and stable.

## Operating Principles

- Protect migration first: redirects, sitemap, robots, canonicals and production routing stay stable.
- Improve existing pages before creating lots of new pages.
- Use one primary page per keyword theme.
- Use real owner/trade knowledge as the content advantage.
- Use Search Console and Ads data to decide priorities.
- Avoid generic SEO activity with no measurable output.
- Avoid thin location pages, duplicate guides and unsupported product claims.
- Build proof slowly with real projects, photos, reviews and supplier/category depth.

## Six Month Plan

### Phase 1: Foundation, Weeks 1-8

Goal: stabilise migration, collect baseline data and improve the highest-intent existing pages.

Work:

- Run Day 0, Day 1, Day 7, Day 14 and Day 30 migration checks.
- Monitor Search Console for indexing, redirects, 404s and canonical issues.
- Fix technical blockers before content expansion.
- Improve top service/category pages based on impressions and positions.
- Enrich the top 10 range pages where verified supplier data exists.
- Add real project proof where available.
- Improve Google Business Profile categories, services, products and photos.
- Start a small Google Ads test only after production is stable.

Success signs:

- No major old URL 404s.
- Sitemap processed cleanly.
- Top pages indexed.
- Initial Search Console query/page baseline established.
- Ads data identifies real high-intent terms.

### Phase 2: Leverage, Weeks 9-16

Goal: use owner expertise and Search Console data to move keywords from positions 4-20 toward page 1.

Work:

- Improve pages with high impressions and weak CTR.
- Add stronger FAQs, comparison tables and internal links to existing pages.
- Publish the first builder contractor guide.
- Publish the first floor preparation guide.
- Strengthen supplier-intent pages with supply-only, stock and lead-time workflows.
- Add real project proof to service/category pages.
- Build 1-3 legitimate supplier/local/business links per month.
- Use Ads enquiry data to prioritise SEO pages and guide topics.

Success signs:

- More queries ranking in positions 4-10.
- More non-brand impressions on service/category pages.
- Better CTR on pages with rewritten titles/metas.
- More enquiries from category/range/product pages.

### Phase 3: Scale, Weeks 17-26

Goal: build topic authority and long-tail product/category coverage without creating thin pages.

Work:

- Expand guide clusters only where existing pages need support.
- Add more verified range/product detail.
- Publish real project/case-study assets.
- Strengthen internal links from guides to service/category/range pages.
- Review competitor and Ads data for gaps.
- Continue legitimate outreach and Google Business Profile updates.
- Revisit duplicate range/canonical cleanup if Search Console shows confusion.

Success signs:

- Top service and category pages hold or improve rankings.
- More range/product long-tail impressions.
- More leads from organic and Ads combined.
- Search Console shows fewer indexing/duplicate issues.

## Weekly Operating Rhythm

Every week:

- Check technical health.
- Review Search Console.
- Pick one priority page to improve.
- Add or improve internal links.
- Enrich one range/product family if verified data is available.
- Update Google Business Profile.
- Review Ads search terms if campaigns are running.
- Record actions and results.

Every month:

- Compare clicks, impressions, CTR and positions.
- Improve 3 existing pages.
- Publish or improve 1 strong guide/project asset.
- Build 1-3 legitimate links or citations.
- Review cannibalisation and duplicate range issues.

## Main Opportunities

1. Builder flooring contractor keywords: high value and less generic than broad flooring terms.
2. Floor levelling and preparation: strong conversion intent and owner expertise advantage.
3. Hybrid and engineered category pages: already strong, good candidates for page 1 improvement.
4. Range pages: old WordPress equity can be turned into useful product acquisition pages.
5. Google Business Profile: strong local visibility opportunity if supported with real photos and service updates.
6. Ads-to-SEO feedback: use paid search to learn which queries convert before investing in long SEO content.

## Main Risks

- Making big content changes too soon after migration.
- Building lots of thin guide pages.
- Letting supplier pages compete with category pages.
- Publishing product/range claims without verified data.
- Ignoring Search Console redirect/canonical warnings.
- Hiring a generic SEO retainer with vague deliverables.
