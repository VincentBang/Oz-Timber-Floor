# Google Ads Learning Plan

Date: 2026-06-04

Purpose: use small controlled Google Ads tests to learn which keywords, services, categories and landing pages produce real enquiries. Ads should feed SEO priorities, not replace SEO.

Do not run broad, uncontrolled campaigns. Do not send traffic to weak or unstable pages before production migration is stable.

## Campaign Structure

Start with small high-intent campaigns only:

| Campaign | Example keywords | Landing page | Goal |
| --- | --- | --- | --- |
| Timber flooring installation | timber flooring installation Sydney, timber floor installer Sydney | `/timber-flooring-installation-sydney/` | Enquiries for installation work |

Avoid starting with broad match. Begin with exact and phrase match, then expand only after clean search term data.

## Negative Keyword Review

Review search terms at least twice per week early on.

Likely negatives to consider:

- free
- DIY only
- job
- career
- salary
- Bunnings if not relevant
- cheap if poor lead quality
- wholesale if not served
- tile installation if not served
- ceramic tile if not served
- bathroom waterproofing if not served
- unrelated supplier/brand names if poor quality

Do not add a negative just because the word is unfamiliar. First check whether it could be a real customer enquiry.

## Ads Data To SEO Rule

Use Ads data to prioritise SEO when:

- a keyword produces real enquiries,
- cost per enquiry is high but intent is valuable,
- a landing page converts well,
- search terms reveal new wording customers use,
- a page gets paid enquiries but weak organic visibility.

SEO actions from Ads:

- improve the matching landing page,
- add FAQs using real customer wording,
- add internal links to the page,
- create a guide only if the query needs education,
- enrich the matching range/category page,
- improve title/meta if organic impressions exist.

## Initial Budget Discipline

Start small and controlled. Do not scale spend until:

- search terms are clean,
- negatives are reviewed,
- conversion tracking is trusted,
- cost per enquiry is known,
- the landing page is stable after migration.

## Stop Or Fix Rules

Pause or adjust if:

- spend occurs with no enquiries after enough clicks,
- search terms are too broad,
- landing page does not match intent,
- contact form or tracking fails,
- enquiries are not serviceable or profitable.
