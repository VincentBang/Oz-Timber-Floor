# Catalogue quality next queue — 2026-09-01

## Decision boundary

This is an evidence-ranked review queue, not an indexation or redirect approval. It does not authorise changes to robots, sitemap membership, canonicals, redirects, titles, descriptions, schema, catalogue facts or visible product copy.

The release process previously had to reconcile 632 catalogue redirect destinations before controlled treatment was safe, and the refined matcher found four additional forced aliases. Current validation reports zero redirects to noindex destinations. That safe state must be preserved: every Class B or D item below needs a route-level evidence or decision package before any indexation treatment changes.

## Method

The ranking uses the 130-row GSC equity map and the catalogue manual-review, quality, redirect and publication evidence already in the repository. Ordering is driven by aggregate clicks, then impressions and impression-weighted average position, followed by current indexability risk, inbound redirect significance, historical internal-link significance, completeness, image certainty, verified-parent safety, commercial value and cannibalisation risk.

Average position is impression-weighted within each named cohort. It is not a sitewide position or traffic total. Redirect significance means current inbound 301 rules plus historical GSC internal-link evidence; there is no target-paired backlink export, so these figures must not be described as backlink counts.

Classes:

- **A — safe code/data cleanup:** deterministic repair is supported by current repository data, but only the named repair is in scope.
- **B — verified business/product data required:** keep the current controlled state until the named evidence is supplied and checked.
- **C — retain current controlled/noindex treatment:** insufficient evidence exists to publish or redirect more specifically.
- **D — separate redirect/indexation decision required:** keep the current safe target until a mapped decision is explicitly approved.
