# Verified Project Entry Template

Use this template only after the business has approved genuine project facts and photographs. Do not turn a common project example into a claimed completed job.

| Field | Required evidence |
| --- | --- |
| Public title | Plain-language project descriptor; avoid client-identifying detail without approval. |
| Location / suburb | Client approval or a privacy-safe generalisation. |
| Property or project type | Verified site information. |
| Product / range | Confirmed product record and selected colour where approved. |
| Approximate area | Verified project measure or an approved range. |
| Preparation issues | Actual site condition, not a generic claim. |
| Installation method | Verified scope. |
| Constraints | Access, staging, timing, acoustic or handover details only if true. |
| Outcome | Factual, non-promissory result. |
| Photographs | Locally stored, permission-confirmed images with meaningful alt text. |
| Related links | Relevant product, range and service pages. |

Keep the current `Projects` page labelled as common project examples until at least one entry has this evidence.
