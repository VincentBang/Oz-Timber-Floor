# Weekly SEO Task Queue

Date: 2026-06-04

Use this queue after production migration stabilises. During the first 14 days after launch, technical migration health takes priority over new content.

## Weekly Checklist

| Task area | Weekly action | Output | Owner note |
| --- | --- | --- | --- |
| Technical checks | Check homepage, top pages, sitemap, robots, old redirects and contact path. | Pass/fail notes and urgent fixes. | Do before content work. |
| Search Console | Review clicks, impressions, CTR, average position, indexing and 404s. | Weekly SEO log. | Focus on pages/queries with movement. |
| Page improvements | Improve one existing service/category/range page. | Better FAQs, proof, internal links, specs or CTA clarity. | Do not rewrite everything at once. |
| Internal linking | Add or improve links from guides/hubs to priority pages. | 5-10 useful internal links per week when relevant. | Keep links natural. |
| Range/product enrichment | Enrich one priority range family with verified data. | Specs, colour clarity, project fit, buying checks. | No unsupported claims. |
| Guide updates | Improve one existing guide or draft one new high-value guide. | Strong guide or improved internal links. | Do not mass publish thin guides. |
| Google Business Profile | Add photos, service updates, Q&A or post if real. | GBP update log. | Use real photos/proof only. |
| Backlink/outreach | Contact one legitimate supplier, builder or partner. | Outreach note and status. | No spam directories. |
| Google Ads learning | Review search terms, negatives, cost per enquiry and landing page quality. | Ads insight note. | Feed winners into SEO priorities. |

## Weekly Prioritisation Rule

Pick work in this order:

1. migration/indexing/redirect problems,
2. pages already getting impressions,
3. high-intent service/category pages,
4. range pages with old WordPress value,
5. guide topics that support high-value pages,
6. proof/backlink work.

## Technical Checks

Run:

- homepage `200`
- top service/category pages `200`
- sitemap `200`
- robots `200`
- sample old URLs `301 -> 200`
- contact form visible
- phone/email visible
- no production `noindex`
- no Netlify/staging canonical leakage

Document any issue before changing files.

## Search Console Checks

Review:

- top pages by clicks,
- top pages by impressions,
- top rising queries,
- top declining queries,
- queries in positions 4-20,
- high-impression low-CTR pages,
- not found / 404,
- redirect errors,
- duplicate canonical issues,
- crawled but not indexed.
